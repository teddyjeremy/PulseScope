# PulseScope color

| Token | Hex | Use |
| --- | --- | --- |
| Ink | #0E141B | Window background, symbol field |
| Panel | #161E28 | Sidebar and status |
| Line | #243140 | Hairlines |
| Text | #E7EEF6 | Primary text |
| Muted | #8B9BB0 | Secondary text |
| Signal | #3DDC97 | Running time, primary accent |
| Trace | #7AA2FF | Waiting time, waveform |
| Marker | #E7B549 | Ready time and timing cursor |

Light theme inverts the surfaces and keeps the same three signal hues, darkened so they stay readable on white. The symbol is a timing cursor crossing a pulse, drawn to stay recognizable at 16 px.
